# test_data/ — Test dataset for QuIVER

## Contents

| File                                          | Description                                  |
|-----------------------------------------------|----------------------------------------------|
| `mini_host.fasta`                             | 10 kb synthetic human chr1 window (for fast host depletion in tests) |
| `single_gt.fastq.gz`                          | 614 ONT reads, HCV genotype 1a (AF009606.1), 500× depth, 5 haplotypes |
| `mixed_gt.fastq.gz`                           | 879 badread ONT reads, ~60% HCV-1a (3 haplotypes) + ~40% HCV-3a (2 haplotypes) + 2% random |
| `samplesheet.csv`                             | Pipeline input samplesheet (FASTQ paths are relative to this file's directory) |
| `expected_outputs/single_gt_genotype_summary.json` | Expected genotype call for single-gt    |
| `expected_outputs/mixed_gt_genotype_summary.json`  | Expected genotype call for mixed-gt     |

## Reference panel

The test profile uses `assets/hcv_references.fasta` (the full 238-sequence panel) rather than
a miniature synthetic panel. This is required because `single_gt.fastq.gz` is simulated from
the real accession `AF009606.1` (H77, genotype 1a), which must be present in the panel for
competitive mapping to assign reads correctly.

`mini_host.fasta` is retained as the host reference for speed — the simulation reads contain
only a small fraction of junk/random sequences that stand in for host contamination.

## Origin of single_gt reads

Simulated with the quasispecies_simulations workflow (`sim_data/1a/C/C_500x_r1/rep1`):
5 haplotypes derived from AF009606.1, 500× target depth, error profile matching ONT R10.4.1.
Expected DEVIDER output: 5 reconstructed haplotypes.

## Origin of mixed_gt reads

Generated by `tests/generate_mixed_gt.py` using **badread v0.4.1** with the
`nanopore2023` error model. Reads are simulated from five real HCV reference
sequences extracted from `assets/hcv_references.fasta`:

| Reference      | Genotype | Length  | Approx. % reads |
|----------------|----------|---------|-----------------|
| 1a_AF009606.1  | 1a       | 9 646 bp | ~20%           |
| 1a_M67463.1    | 1a       | 9 416 bp | ~20%           |
| 1a_EF407457.1  | 1a       | 9 286 bp | ~20%           |
| 3a_D17763.1    | 3a       | 9 456 bp | ~20%           |
| 3a_D28917.1    | 3a       | 9 454 bp | ~20%           |

Total: ~60% genotype 1a (3 haplotypes), ~40% genotype 3a (2 haplotypes), plus
2% random reads. The natural divergence between strains within each genotype
gives DEVIDER signal to reconstruct per-branch haplotypes.

To regenerate:
```bash
python3 tests/generate_mixed_gt.py \
    --panel assets/hcv_references.fasta \
    --output test_data/mixed_gt.fastq.gz
```

Badread parameters (fixed for reproducibility): `--quantity 100x --length 8000,2000 --seed 200 --random_reads 2`
